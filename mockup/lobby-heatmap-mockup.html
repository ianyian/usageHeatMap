Session

One tap applies tuning that fits the space. Canteen/Lobby: short 10-minute memory for busy areas. Warehouse: 6-hour retention and lower confidence, so a brief overnight pass-through stays visible until security reviews it.
How long detected activity stays "remembered" before fading from the heatmap. 10 minutes suits a lobby or canteen; somewhere quieter overnight — like a warehouse aisle a person only passes through briefly — benefits from a longer window like 6h or 24h so a brief, faint pass-through doesn't disappear before anyone reviews it.
Off by default to save disk space — the heatmapLog alone supports replay, so periodic photos are optional visual context, not required data. When enabled, this interval controls how often a plain JPEG is saved to logPicture/.
Detection events are consolidated into one record per 5 seconds — each record carries every detected position in that window plus the peak headcount — roughly 12× fewer log lines than per-frame logging, with the same replay quality.

Presentation

Shows lively simulated activity regardless of actual room occupancy — turn this on before a live presentation so the heatmap looks populated even in an empty or quiet room. Turn it off to see the real camera feed.
While Demo mode is on, the simulated headcount wanders smoothly within this range across the counters and tables, instead of a fixed number.
